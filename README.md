# Sylvie, Huizhi Zhao — Orchid Portfolio

A standalone static website. No build step, dependencies, or OpenAI services required.

## Deploy on GitHub Pages

1. Create a public GitHub repository (for example, `portfolio`).
2. Extract this ZIP. Upload its contents to the repository root: `index.html`, the other HTML pages, `style.css`, `assets/`, and `.nojekyll`. Do not upload the ZIP itself.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Once deployment finishes, Pages will display your website link.

For a profile site at https://YOUR-USERNAME.github.io/, name the repository YOUR-USERNAME.github.io. Otherwise the address is typically https://YOUR-USERNAME.github.io/portfolio/.

## Edit

- index.html: orchid navigation and your name.
- education.html, machine-learning.html, software-engineering.html, digital-designing.html, personal.html: subpage content.
- style.css: typography, color, layout, and petal label positions.
- assets/orchid.jpeg: homepage photograph.

All links use relative paths so project and profile Pages sites both work.
You can open index.html directly in a browser to preview locally.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
